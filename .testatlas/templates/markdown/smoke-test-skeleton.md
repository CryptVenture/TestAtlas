# Smoke test skeleton

This template is the language-agnostic shape of every smoke test emitted by
`scripts/generate-automation.js --smoke`. The script writes a `.md` file under
`_testatlas/tests/generated_automation/smoke/`. Smoke tests are intentionally
lightweight — a single checklist that proves the flow is at least reachable.

## Status lifecycle

`generated-but-not-validated` → `validated` → `committed` → `flaky`

Status lives in the companion `<slug>.meta.json`.
