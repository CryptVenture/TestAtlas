## How scores are computed

PRD §7.15. Each metric is a deterministic function of brain state — coverage,
issue counts by severity, drift status, evidence freshness — rendered to an
integer 0-100. Re-running the command on the same brain state produces the same
score (no randomness, no LLM judgment).
