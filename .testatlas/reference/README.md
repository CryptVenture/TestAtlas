# .testatlas/reference — Long-Form Rationale

Files in this directory are **read on demand**. Bootstrap (`../bootstrap.md`) names the rules; this directory explains the *why*. A typical command does NOT load reference files. Read one only when the bootstrap rule it backs is unclear, contested, or extended.

## Index

- [`severity.md`](./severity.md) — severity vocabulary detail (critical / high / medium / low / enhancement).
- [`confidence.md`](./confidence.md) — confidence vocabulary detail (confirmed / strong-suspect / needs-validation).
- [`capabilities.md`](./capabilities.md) — capability vocabulary detail (browser / shell / web-fetch / MCP / file-write) and the per-capability action matrix.

Each shard begins with a "When to read this" line per the read-on-demand contract.
