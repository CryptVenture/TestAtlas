# 05 Assumptions

> Updated automatically by every TestAtlas command. Human notes outside the generated blocks are preserved across runs.

This document captures every assumption the testing campaign is making about the product. Each assumption should be explicit, tied to a source or rationale, scored for confidence, and have a validation path. Assumptions are dangerous when implicit — making them explicit is the point of this document.
